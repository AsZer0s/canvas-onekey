# 画布一键包 使用说明
> **下载**：到本仓库右侧的 **Releases** 下载「canvas-onekey-v1.0.0.zip」（约 22MB，已含 bin\uv.exe），解压到本机硬盘后双击「启动画布.bat」。直接下载源码缺少 uv.exe，无法启动。

双击一个文件，自动检测显卡、按显卡推荐并下载模型，然后打开「无限画布」。用画布就能在自己电脑上做文生图、多图参考改图、文生视频、首帧动起来。全程在本机运行，不用账号、不用 API Key。

> **许可证**：画布来自开源项目「无限画布」（GitHub：drkk5282-gif/Infinite-Canvas-Open-Source-Project）。作者只允许**个人学习、教学和免费、非商业分享**，禁止出售、收费部署或用于营利。分享这个一键包时，必须连同 `LICENSE` 和 `DISCLAIMER.md` 一起发，不能收费。

## 一、电脑要求

| 项目 | 要求 |
| --- | --- |
| 系统 | Windows 10 / 11（64 位） |
| 显卡 | NVIDIA 显卡，驱动 570 以上（推荐 580 以上）。AMD、Intel 显卡和苹果电脑不支持 |
| 显存 | 生图至少 12GB；做视频（MiniMax H3）：12～23GB 用 GGUF 压缩版（慢一些、画质略降），24GB 以上用 int8 版 |
| 内存 | 32GB 起；做视频建议 64GB 以上（非 50 系的卡做视频至少 48GB） |
| 硬盘 | 只装生图约 35GB；生图 + 视频约 110GB。建议放在固态硬盘 |
| 网络 | 第一次要下载程序和模型。国内网络慢，可以在管理页勾选「使用国内镜像」 |

显卡和推荐的对应关系，一键包会自动判断：

| 显存 | 推荐安装 |
| --- | --- |
| 12～15GB（如 3060 12G） | Qwen 2.1 图片（文本编码器用省显存的 W4A8 版）；可选 H3 GGUF 压缩版 Q3（默认不勾，实验） |
| 16～19GB（如 4060Ti 16G、4080、5080） | Qwen 2.1 图片 + 精细 40 步 + 单反写实 + 电影剧照 + H3 首帧/文生视频 GGUF 压缩版 Q4；可选 MOSS、Ref2VA |
| 20～23GB | 同上，H3 用 GGUF 压缩版 Q5（画质更好） |
| 24～31GB | 上面全部 + H3 首帧/文生视频（剪枝 int8）。24GB 是下限，先用 Turbo 档、短时长试 |
| 32～47GB（如 5090） | 上面全部 + H3 参考图生视频（剪枝 int8） |
| 48GB 以上 | H3 换成完整 int8 版，画质最好 |

- **50 系显卡**（Blackwell）：H3 的文本编码器用 NVFP4 版（15.7GB），省显存。
- **其他显卡**：用不了 NVFP4，H3 文本编码器用 int8 版（27GB），更吃内存。
- **GGUF 压缩版 H3**（12～23GB 显存）：视频主模型用社区作者 Abiray 的剪枝 GGUF（Q3 / Q4 / Q5），文本编码器和 VAE 仍是官方版，会自动装 ComfyUI-GGUF 插件。实测（在 5090 上限制成只能用约 12GB 显存）：Q3 + 快速 8 步 Turbo，5 秒竖屏视频约 3.5 分钟出片，带声音，两种文本编码器都能用。注意这只模拟了显存，没模拟算力：3060、4060 这类卡算力只有 5090 的几分之一，实际可能要 10～20 分钟一条。小显存的卡**请用「快速8步 Turbo」档、4～6 秒**，均衡 20 步会慢两倍多。画质比 int8 版差一些，正式镜头最好还是在 24GB 以上的卡上出。

## 二、第一次使用

1. 把整个文件夹解压到**本机**一个空间够大的盘，比如 `D:\画布一键包`。**不能放在 NAS / 网络共享文件夹里直接双击**（会提示你先复制到本机）：模型有几十到上百 GB，从网络盘读写太慢，Python 环境也装不上。路径里最好不要有空格；如果遇到奇怪的报错，换成纯英文路径（比如 `D:\canvas`）再试。
2. 双击 **`启动画布.bat`**。会弹出一个黑窗口，**不要关它**，关掉画布就停了。第一次会先准备 Python 环境，大约 1 分钟。
3. 浏览器会自动打开管理页 `http://127.0.0.1:10020`：
   - **① 电脑自检**：显示显卡型号、显存、架构、驱动、内存和硬盘剩余空间。
   - **② 选择要安装的功能**：已经按你的显卡勾好了推荐项，灰色的是这张卡跑不动的，可以自己增减。
   - 点 **「开始安装」**：先装 ComfyUI 和 PyTorch（约 8GB），再下载模型。下载可以随时点「暂停下载」，下次点「开始安装」会接着下，不会从头来。
4. 装完点 **「③ 启动画布」**，等三个状态灯都变绿，画布 `http://127.0.0.1:10027` 会自动打开。

**以后再用**：直接双击 `启动画布.bat`，装好的话会自动启动并打开画布。画布顶部中间的「模型管理」按钮能回到管理页补装模型。

## 三、在画布里用

| 想做什么 | 节点 | 模型 | 怎么连 |
| --- | --- | --- | --- |
| 文字生图 | 图片节点 | Qwen 2.1 图片 | 不连图，写提示词 |
| 多图参考改图、合成 | 图片节点 | Qwen 2.1 图片 | 最多连 4 张；场景放图 1、人物放图 2；点图片编号能设为图 1（决定画幅） |
| 写实照片 / 电影感 | 图片节点 | Qwen 2.1 图片 → 生成档位选「单反写实 40步」或「电影剧照 40步」 | 同上 |
| 另一种画风的文生图 | 图片节点 | MOSS-Image | 只写文字，不连图 |
| 文生视频 | 视频节点 | H3 首帧/文生视频（FL2VA） | 不连图 |
| 图片动起来 | 视频节点 | H3 首帧/文生视频（FL2VA） | 连 1 张图当首帧；连 2 张图是首尾帧 |
| 人物 / 场景参考生成镜头 | 视频节点 | H3 参考图生视频（Ref2VA） | 连 1～7 张参考图 |

**姿势参考**：画布顶部的「姿势参考 ↗」会打开一个免费的姿势参考图网站（外部网站，白膜人偶，各种站姿、坐姿、双人动作，多个角度）。用法：在网站上挑一张，单张保存到电脑，拖进画布变成图片节点，连到 Qwen 图片节点，提示词写"人物摆出图 X 的姿势"。该网站允许免费使用、也允许作品商用，但**禁止批量下载和再分发**，所以一键包没有打包这些图，也不要批量抓取或转发给别人。

**导入自己的参考图文件夹**：管理页 ④「导入我的参考图」→ 点「选择文件夹…」选一个放参考图的文件夹（或者直接粘贴路径）→ 填个画板名 → 「导入成画板」。导入完刷新画布，在节点上点「+」打开「选择素材」，左上角下拉框切到这个画板，就能按子文件夹浏览、搜索、勾选添加。
- 子文件夹会变成弹窗里的小分组；子文件夹叫「人物 / 角色」「场景」「道具」的，会自动归到对应类别。
- 支持 PNG / JPG / WebP，单张 50MB 以内，一次最多 3000 张；太多就分几个文件夹导入。
- 每导入一次就新建一个画板，不会改动已有的画板。不想要了，在画布主页右键这个画板删除即可。
- 只导入你自己有权使用的图片：自己拍的、自己画的、网站允许单张使用后你一张张存下来的。

**Qwen 生成档位**（图片节点上的「生成档位」）：
- **默认**：8 步 Turbo，最快，几十秒一张。
- **精细 40步**：标准版底模，更听光线和视线的描述，几分钟一张。
- **单反写实 40步**：最自然的写实照片感，适合白天戏、定妆照。
- **电影剧照 40步**：偏冷、胶片电影感，适合夜戏、氛围镜头。

**H3 生成档位**（视频节点上的「比例 · 档位 · 秒数」）：
- **均衡20步**：默认，质量和速度平衡。
- **细化30步**：最细，最慢。
- **快速 Turbo**：8 步（FL2VA）或 4 步（Ref2VA），先看动作和构图用。

**H3 提示词小贴士**：
- 台词直接写进提示词，用引号括起来，H3 会同时生成声音。
- 结尾加一句"纯净画面，无字幕"，能减少画面里烧出字幕。即使写了，H3 有时仍会把台词烧成字幕（一键包实测时就出现过），出片后检查画面下方，有字幕就换个种子重抽。
- 一张显卡一次只跑一个任务，多点几个会自动排队。
- 图片和视频来回切换时，第一条会多等 1～2 分钟加载模型。

## 四、文件夹说明

| 文件夹 | 放什么 |
| --- | --- |
| `启动画布.bat` | 双击启动 |
| `bin\` | uv（装 Python 和依赖用的工具） |
| `launcher\` | 启动器：自检、下载、管理页 |
| `canvas\` | 画布程序（上游源码 + 本机模型接入层 `canvas\onekey\`） |
| `模型\` | 下载的模型（第一次安装后才有） |
| `输出\` | ComfyUI 生成的原始图片和视频 |
| `data\` | 你的画板、素材和设置（第一次运行后才有）。分享一键包时**不要带上这个文件夹** |
| `runtime\` | Python、ComfyUI、PyTorch（第一次安装后才有，约 8GB） |

**已经装过 ComfyUI、手上有模型**：管理页「下载设置」里填旧 ComfyUI 的 `models` 文件夹。同名、同大小的文件会直接链接或复制过来，不用重下。

## 五、常见问题

- **管理页显示"没找到 nvidia-smi"**：没装 NVIDIA 驱动，或者不是 NVIDIA 显卡。去 NVIDIA 官网装最新驱动。
- **提示驱动太旧**：到 NVIDIA 官网更新到 570 以上（推荐 580 以上），再双击启动。
- **下载很慢或连不上**：管理页 → 下载设置 → 勾选「使用国内镜像」。
- **生成时报"显存不足 / out of memory"**：H3 换「快速 Turbo」档、把秒数改短；或者关掉其他占显存的程序（游戏、其他 AI 软件）。
- **视频生成特别慢（每一步一两分钟）**：多半是显存被别的程序占了，H3 放不下，只能边算边从内存搬。微信、剪映、浏览器、NVIDIA 叠加层、游戏都会占显存。做视频前关掉它们再生成；管理页自检会提示当前被占了多少显存。实测同一张 5090，桌面上开着微信、剪映等软件时每步约 90 秒，而在专门跑模型、不开别的软件的机器上要快得多。
- **画布打不开 / 生成报"连不上本机 ComfyUI"**：看管理页 ③ 的状态灯，点「出问题时看后台日志」查看报错；也可以点「停止」再「启动画布」。
- **想彻底删除**：关掉黑窗口，直接删除整个文件夹。一键包不往系统盘写东西，也不改系统设置。
